# Farm Rush CPI

A single-level parking and fruit-loading game built with Three.js.

Tap trucks with a clear path to collect matching fruit. Hold empty space to speed up the conveyor.

The tenth gameplay input opens Farm Rush Fever on the App Store. Restarting resets the input count.

Hosted with GitHub Pages. No build step is required.

Run conveyor motion checks with `node --test tests/conveyor-motion.test.mjs`.
